# 웹 로그인 유지

기존처럼 `flutter run -d web-server`로 실행합니다. 별도 인증 서버는 필요하지 않습니다.

- Google 로그인 성공 시 계정 ID, 이메일, 이름, 프로필 사진 주소만 브라우저에 저장합니다.
- 같은 브라우저와 같은 주소(프로토콜·호스트·포트)에서 새로고침하면 저장된 계정을 복원합니다.
- 로그아웃하거나 사이트 데이터를 삭제하면 계정 정보가 지워집니다.
- 기존 버전은 계정 정보를 저장하지 않았으므로 업데이트 후 첫 로그인은 필요할 수 있습니다.

이 기능은 앱에서 계정을 기억하는 기능입니다. 저장된 계정 정보는 Google 인증 증명이나
시트 접근 권한으로 사용하지 않습니다. ID/refresh token은 저장하지 않습니다.
시트 접근 토큰(access token)은 **같은 탭의 sessionStorage**에 원래 만료 시각과 함께 임시 저장합니다.
새로고침 시 Google에서 토큰의 계정·앱 ID·권한·남은 유효기간을 확인해 재사용합니다.
만료 30초 전부터 재연결이 필요하며, 새로고침으로 유효기간이 늘어나지 않습니다.
일시적인 네트워크 장애에는 저장된 토큰을 삭제하지 않고 재시도를 안내합니다.
탭을 닫거나 로그아웃·계정 변경을 하면 시트 권한을 다시 연결해야 할 수 있습니다.
브라우저의 탭 복구 기능은 sessionStorage를 복구할 수 있지만 원래 만료 시각은 그대로 적용됩니다.
토큰이 없거나 만료·무효화되면 **기억한 계정과 시트 권한 연결 화면**이 표시됩니다.
권한 연결 시 실제 토큰 소유 계정을 Google에서 확인한 뒤 시트에 접근합니다.
권한 창에서 다른 계정을 선택한 경우 해당 계정으로 화면과 저장 정보를 갱신합니다.

확인 순서: 로그인 → 시트 권한 연결 → 시트 조회 → 같은 탭 새로고침 → 권한 창 없이 시트 조회.
로그아웃 후 새로고침하면 로그인 화면으로 돌아와야 합니다.

```bash
flutter test test/web_login_session_test.dart test/web_token_restore_test.dart test/main_login_restore_test.dart test/google_auth.dart
```
